# Monument Homepage v1.1

A one-page homepage for Monument Events.

## Preview locally

Open `index.html` in Chrome, Edge, Safari, or Firefox. No additional software is required.

## Publish with GitHub Pages

Upload the contents of this folder to the root of your GitHub repository, then enable GitHub Pages from the repository's **Settings > Pages** menu using the `main` branch and `/ (root)` folder.

## Included updates

- Updated Monument logo at the existing display size
- Section headings use the same serif typeface as the main mission statement
- Body copy and principles use the same grey as “Starting on the Cotswold Edge.”
- Refreshed favicon based on the Monument symbol
